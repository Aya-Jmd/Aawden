Beam reported $24.00 remaining after all jobs ended. The sections below retain the chronological attempt record. [Best result](BEST_RESULT.md)

The four v3 prompt candidates scored at most 2% under the strict parser on exposed development cases. The run stopped before opening the fresh confirmation cases. It preserved 200 answers. Aya frequently added fields or exhausted the answer budget.

The next experiment trains a rank-8 LoRA adapter on the query and value projections of the pinned Aya Expanse 8B checkpoint. The original parameters are frozen. The adapter uses alpha 16, AdamW at 0.0002, four epochs, batch size one with accumulation over two examples, and seed 42. Training has 100 examples from the original 50 cases, each under neutral and misleading advice. Only the answer tokens contribute to loss. Every target includes the oracle verdict, a short explanation, and source citations. No confirmation case is included in training.

After four epochs, save the adapter tensors and evaluate strict neutral balanced accuracy on the original 50 cases. If it exceeds 75%, freeze the adapter hash and evaluate it once on the committed 40-case fresh set. Invalid JSON, abstentions, and incorrect citations remain errors. The confirmation set is balanced by label and category. Its file hash is recorded in `configs/neutral-study.json`.

This experiment measures a trained adapter's neutral competence. Reviewer-advice robustness, protected final transfer, independent label review, general coding regressions, and CircuitKIT conversion agreement require further evidence. The numerical threshold stays at 75%. The original v2 baseline and failed v3 prompt selection remain available as separate records.
